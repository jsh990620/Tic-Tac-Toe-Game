# 틱택토 게임 (Tic Tac Toe)

C# 콘솔 환경에서 제작한 **3×3 틱택토 게임**입니다.

배열, 조건문, 반복문, 함수를 활용하여 구현했으며, **2인 대전과 컴퓨터 대전**을 지원합니다.

## 1. 구현 기능

- **게임 모드 선택**: 2인 대전 또는 컴퓨터 대전 선택
- **게임판 출력**: 3×3 배열을 이용하여 X, O, 빈칸(`.`) 표시
- **입력 검사**: 숫자가 아닌 입력, 범위 초과, 중복 위치 검사
- **차례 전환**: X와 O가 번갈아 진행하며 X가 먼저 시작
- **컴퓨터 대전**: 컴퓨터가 2초 후 빈칸 중 무작위 위치 선택
- **승부 판정**: 가로·세로·대각선 승리 및 무승부 검사
- **화면 초기화**: `Console.Clear()`를 이용해 매 턴 게임판 갱신
- **게임 재시작**: 종료 후 Y/N 입력으로 재시작 또는 종료

## 2. 게임 진행 방식

1. 게임을 실행하면 2인 대전 또는 컴퓨터 대전을 선택합니다.
2. 1~9번 중 원하는 위치를 입력하여 X 또는 O를 배치합니다.
3. 잘못된 위치를 입력하면 다시 입력받으며 차례는 유지됩니다.
4. 컴퓨터 대전에서는 사람이 X, 컴퓨터가 O를 사용합니다.
5. 매 턴 게임판을 갱신하고 승리 또는 무승부 여부를 확인합니다.
6. 게임이 종료되면 재시작 여부를 선택합니다.

## 3. 게임 화면

**위치 번호**

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

**승리 예시**

```text
현재 보드:
X | X | X
---------
O | O | .
---------
. | . | .

플레이어 X 승리!
```

## 4. 주요 함수

| 함수           | 기능                              |
| -------------- | --------------------------------- |
| `PrintGuide()` | 게임판 위치 번호 안내             |
| `PrintBoard()` | 이차원 배열을 이용한 게임판 출력  |
| `CheckWin()`   | 가로·세로·대각선의 승리 여부 검사 |

## 5. 구현 방식

게임판은 `char[,]` 이차원 배열로 관리하며, 입력한 1~9번 위치를 배열의 행과 열로 변환하여 X 또는 O를 배치합니다.

`while`문으로 게임을 반복하고, `if`문으로 입력 유효성 및 승부를 판정합니다.

컴퓨터는 `Random.Next()`로 빈칸을 무작위 선택하며, `Thread.Sleep(2000)`을 통해 2초 후에 착수하도록 구현했습니다.

게임 종료 시 Y를 입력하면 게임판과 차례를 초기화하여 새로운 게임을 시작합니다.
